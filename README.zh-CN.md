# codex-cost

**你的 Codex 额度到底花在哪了 —— 以及换个模型会花多少。**

其它用量工具都在回答"我用了多少"。这个回答它们不答的两个问题：

- **这笔花费的构成** —— 新增输入、模型输出，还是每次请求的固定开销？
- **同样这些活，换个模型要花多少？**

第二个才是重点。**模型选择的影响远超其它所有优化**，而没有任何工具给你这个对照。

住在刘海里；没有刘海的 Mac 自动退回菜单栏。原生 Swift，零依赖，数据不出本机。

## 安装

```bash
git clone https://github.com/kongleiwork-art/codex-cost
cd codex-cost && ./build.sh && open CodexCost.app
```

只需要 Xcode 命令行工具（`xcode-select --install`），别的都不用。

应用未签名，**首次打开要右键 → 打开 → 再点「打开」**，之后就正常了。

## 看到什么

收起时是刘海旁边一条：当前模型、额度水位、一个圆环。点开是完整面板 —— 成本拆解、
两个额度窗口、这段时间用了哪些模型、以及同样的 token 换成其它模型各要多少。

5 小时额度到 **80% 和 95%** 时发通知，带上燃烧速率、还能撑多久，以及
——当换个便宜模型能省下明显额度时——建议换成哪个。

## 成本模型

这是别的工具没有的部分。系数来自 **23 个实验组、421 次受控调用**，每次只改一个变量。
原始数据和实验框架都在 [`research/`](research/)。

每个模型三个系数，而不是一个乘数：

| | 新增输入（1% 能买） | 输出+推理（1% 能买） | 每次请求 |
|---|---|---|---|
| `gpt-5.6-sol` | 41,398 tok | 15,450 tok | 0.0667% |
| `gpt-5.5` | 48,137 tok | 17,965 tok | 0.0574% |
| `gpt-5.6-terra` | 46,000 tok | 17,167 tok | 0.0600% |
| `gpt-5.6-luna` | 免费 | 免费 | 免费 |
| `gpt-6-astra` | 15,415 tok | 2,495 tok | 0.3514% |

**单一乘数描述不了 `astra`。** 它三个成分相对 `sol` 分别是 2.7× / 6× / 5.3×，
所以"等效乘数"完全取决于模型说了多少话，在 3.4× 到 11× 之间飘。
早期那些互相矛盾的估计，全是同一个现象在不同角度下的投影。

## 四条能直接用的结论

**缓存输入完全不计费。** 不是打折，是根本不出现在成本模型里。一个带着 22 万 token
上下文的会话，每轮成本只比带 4 万的高一点点，因为除了最新几千 token 之外全是缓存。
**别为省额度清上下文** —— 重新读回来要付全价。

**每次请求有固定底价。** `sol` 上是 0.0667%，跟请求大小无关。15 次请求就吃掉 5 小时
窗口的 1%，哪怕什么都没返回。也就是说一个窗口最多约 1,500 次请求。
**冗余的工具调用即使很小也很贵。**

**effort 档位没有独立乘数** —— 在 `sol` 上。调高档位变贵纯粹是因为产生了更多推理
token，费率本身不变。五个档位各测 15–22 次，乘数全部落在 1.0 ± 0.1。
实际上 `sol` 开到 max 仍比 `astra` 开 low 便宜三分之一 ——
**先把 effort 开满，再考虑换模型**，这跟大多数人的直觉相反。

**别让 `astra` 长篇思考。** 它的输出和推理 token 是 `sol` 的约 6 倍，而输入只贵 2.7 倍。
让它干短平快的活还能接受，让它写长推理是你能做的最贵的事。

## 口径与误差

摊开写，因为这些数字只有在你知道误差范围时才有价值：

- **token 数是估算的**，按工具返回内容的体积换算，不是账单数字。看比例，别对账。
- **额度读数是整数。** 一个只跑到 Δ=4% 的实验组，光舍入就带来 ±12% 误差。
  只有跑到大 Δ 的组才可信。
- **额度读数是事件驱动的。** 日志只在 Codex 发请求时才写，所以"当前用量"永远是
  上次请求那一刻的值。窗口滚动后如果没再用过，最后那条读数就是陈旧的 ——
  CodexCost 用 `resets_at` 判断这种情况。**不做这个检查的工具，会在空窗口上显示 99%。**
- **5 小时限额是滚动窗口，不是到点清零。** 数据里出现过 43 分钟内从 84% 掉到 0%，
  固定窗口做不到，滚动窗口在一批集中用量整体过期时可以。
- **`sol` 可靠**（22 组，按次归一化回归 R² 0.987）。**`5.5` 和 `terra` 在现有分辨率下
  与 `sol` 无法区分** —— 误差棒重叠，三个都当 ≈1× 用。**`astra` 和 `luna` 各只有
  30–40 次样本**，当数量级看，别当精确值。
- **在单一账号、`plus` 套餐、2026 年 9 月测的。** 计量规则可能变。
  `research/` 里的框架有个 `control` 组专门用来复检。

**别把这些当成省钱依据。** 订阅制下省的 token 不变成钱，变成的是撞墙前的余量。

## 隐私

只读本地 `~/.codex/sessions`。无网络请求、无遥测、不上传任何东西。
面板只显示聚合数字 —— 不含 prompt，不含文件内容。
